# DOLU.ai Landing Mockup

Bu depo, DOLU.ai için hızlı bir landing page mockup'ı içerir. Tasarım, Türkçe odaklı ve nöropazarlama vurgulu bir SaaS tanıtım sayfasıdır. Tailwind CSS CDN üzerinden kullanılır; dosyayı yerel olarak açmak için yalnızca `index.html`'i tarayıcıda açmanız yeterlidir.

## Özellikler
- Hero, omnichannel özellikler, benzersiz "Müşteri Bulma" bölümü
- Sektör grid'i, fiyatlandırma tabloları, SSS ve demo formu
- Dark arayüz, gradient ve glassmorphism detayları
- Mobil öncelikli, responsive grid ve tipografi

## Kullanım
1. Depoyu klonlayın.
2. `index.html` dosyasını tarayıcıda açın.
3. İsteğe bağlı olarak tasarımı Next.js + Tailwind projesine taşıyın.

## Notlar
- Görsel/animasyon içeren bölümler temsilidir; gerçek veri ve entegrasyonlar eklenebilir.
- Metinler TR odaklıdır; EN ve AR için i18n entegrasyonu eklenebilir.
